Data handling: images decoded in memory (cv2.imdecode); video temp file deleted in finally: (tested). Nothing persisted, no biometric logging. Every response carries the disclaimer.
Outputs: risk band, probability, confidence, limiting factor, counts, blurred heat map. Never minutiae coordinates, templates or a clean ridge image.
Designed · not deployed

aws/infra (CDK, synthesises to 50 resources): API Gateway → ALB → Auto Scaling group of Graviton4 instances on the Cloud Optimized OpenCV (COOL) AMI, S3 for datasets/results. aws/cool_benchmark: COOL-on-Graviton vs stock-x86 harness. Neither was run, so the COOL award is not claimed.

AWS OpenCV 5 workload Agent (perceive → decide → act) Designed, not deployed GATTACA is a privacy-awareness tool. It estimates exposure risk; it does not store biometrics or defeat security systems.
