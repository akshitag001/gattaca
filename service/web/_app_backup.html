    What format are fingerprints actually stored in? (and what GATTACA will not give you)

    Forensic and biometric systems rarely store a picture of a ridge. They store a compact minutiae template: a list of the points where ridges end or split, each as a position, an angle and a type.

    ISO/IEC 19794-2 minutiae record (one finger) ┌──────────┬──────────┬────────────┬─────────────┬──────────┐ │ x (px) │ y (px) │ angle (°) │ type │ quality │ ├──────────┼──────────┼────────────┼─────────────┼──────────┤ │ 182 │ 96 │ 41 │ ridge-ending│ 74 │ │ 204 │ 158 │ 126 │ bifurcation │ 88 │ │ … │ … │ … │ … │ … │ └──────────┴──────────┴────────────┴─────────────┴──────────┘ Related standards: ANSI/NIST-ITL 1-2011 (exchange), WSQ (500-ppi image compression).
    GATTACA deliberately does not emit this. It reports how many ridge features it found and how clearly, but never their coordinates, never a template, and never a clean, enhanced ridge image you could feed to a matcher. That is the whole point: a privacy-awareness tool must not become the extraction tool it warns you about. The heat map below shows where and how much is exposed — not the print itself.
